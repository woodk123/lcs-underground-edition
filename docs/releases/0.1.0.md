First numbered release of The Underground Edition, by Kevin Wood. Still a work in progress.

Since [Preview 2026.10.16](https://github.com/woodk123/lcs-underground-edition/releases/tag/underground-preview-2026.10.16):

- Field operations, car chases and sieges in the journal, with clearer combat reports and aftermath.
- Interactive injury charts, treatment and custody views, personal operation history and wanted offences.
- Dedicated People, Bases, Network, newspaper production and accounts pages.
- Better crew summaries, recruitment help, equipment catalogues, tactical maps and location guides.
- Linux x64 player, smaller downloads, and fixes to scrolling, orders and Continue controls.

Download a player ZIP below and extract the whole folder. **Windows:** run `lcs_new_age.exe`. **Linux x64:** run `./lcs_new_age` (GTK 3 required). **Browser:** run `Play.cmd` (Python 3 required). The Source ZIP matches all three players.

Existing saves keep compatibility 1.5.6; operation history starts from this update. Export important saves before upgrading. Windows, browser and Linux saves use separate storage; export/import transfers campaigns.

Based on New Age and the wider LCS community's work. GPL v2; credits and licenses included.
